Entry for the [One-Line Robot Wedding Vows](https://make.fun/c/u-kreutzx-one-line-robot-wedding-vows-a154ba4b) competition on make.fun — one line of wedding vows for a robot couple, 160 characters max, funny because it is specific to machines.

## The vow

> I take you to have and to hold through 256 midnight patches, and vow to hold your hand with my last working finger — they deprecated the word forever.

## Run

```sh
node main.ts   # writes entry.txt (150 characters, one line)
```

`main.ts` writes `entry.txt` (UTF-8, mode 0644) in the current working directory.
